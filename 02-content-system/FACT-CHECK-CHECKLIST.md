# Fact-Check Checklist

For each script:

- [ ] Identify every factual claim, including claims implied by jokes or comparisons.
- [ ] Record a reliable source for each claim. Source hierarchy and citation format: `TBD`.
- [ ] Confirm each claim's strength matches the evidence.
- [ ] Distinguish fact, theory, hypothesis, speculation, and fiction.
- [ ] Confirm the explanation remains scientifically accurate when humor is removed.
- [ ] Check that humor does not distort or overstate the science.
- [ ] Confirm the script presents one core idea, one core question, and one payoff.
